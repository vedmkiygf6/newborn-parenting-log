# 怎么给孕中期孕妇补钙

> 更新时间：2026-09-17 (UTC+8)

怎么给孕中期孕妇补钙

孕中期是指孕十三周到孕二十七周期间，这个期间孕妇早孕的反应大多都小了，而且食量明显增大。因为这个时期胎盘已经形成，宝宝进入快速成长期，需要的营养更多。因此，孕中期当然也不能忘记补钙这项大事！怎么给孕中期孕妇补钙呢？

一般来说，每天要喝500毫升牛奶或酸奶，再吃一些虾皮、腐竹、黄豆以及绿叶蔬菜等钙含量丰富的食物，多享受日光浴，适量运动，基本上就能够满足一天的钙需求量。对于不习惯喝奶的孕妈，就需要及时进行钙剂补充了，同时多晒太阳，促进身体对钙的吸收。

孕中期孕妇补钙补多少

孕妇补钙一定要科学，注意剂量。那么，孕中期孕妇补钙补多少好呢？正常情况下，孕中期孕妇每天的钙需求量是1000毫克，比孕早期要多了200毫克，也就是比普通成年人的需求量多一些。怎么知道自己是不是要补钙呢？还缺多少呢？那就要求孕妇本人能学会对膳食中摄入的钙，做出一个大致的判断。比如孕中期大概需要1000毫克钙，就可以将自己每天吃的含钙食物用表格列出来，根据这些数据来大致判断一下自己每天摄入的钙是否足够。

孕妇一般从孕4月（即孕中期）开始考虑补钙的问题，因为胎儿进入了快速增长期，骨骼和牙齿等发育都需要钙的支持，为了保证胎儿身长的正常增长，必须保证脊柱、四肢、头颅骨及牙齿的正常钙化(或骨化)，就一定要补充足够的钙。孕妈从孕中期开始加速钙的吸收和体内钙的贮存，这个时候如果得不到充足的钙质，那么就可能会使得准妈妈血钙降低，诱发小腿抽筋或手足搐搦，严重时准妈妈出现骨质疏松、骨质软化；其次，会使孩子患先天性佝偻病，孩子出生后因体内的钙储备量不足，新生儿期容易出现手足搐搦症，表现为烦躁不安、肌肉抽搐、面色发青、喉痉挛、腕踝阵挛等。

孕中期孕妇补钙吃什么

孕中期孕妇补钙仍主要从食物入手，这个时候孕妈妈的食欲会比较好，食量大大增加。孕妈妈除了每天吃主食米面之外，还应该多吃一些鱼类、动物内脏、豆制品、鸡蛋、牛奶等富含有蛋白质以及钙质的食品。富含有维生素类的蔬菜和水果，准妈妈们也不能错过哦！色蔬菜中的小油菜、小白菜、芥蓝、芹菜等，都是非常好的补钙蔬菜。每100克的绿叶蔬菜中的含钙量已经达到了230毫克左右，而小白菜、油菜、茴香、芫荽、芹菜等，每100克中所含有的钙质元素甚至有150毫克。

下面我们就具体看看哪些食物含有丰富的钙质，孕妈妈可以收藏起来，记得适量多吃：

乳类与乳制品：牛、羊奶及其奶粉、乳酪、酸奶、炼乳。

豆类与豆制品：黄豆、毛豆、扁豆、蚕豆、豆腐、豆腐干、豆腐皮等。

海产品：鲫鱼、鲤鱼、鲢鱼、泥鳅、虾、虾米、虾皮、海带、紫菜、蛤蜊、海参等。

肉类与禽蛋：羊肉、猪脑、鸡肉、鸡蛋、鸭蛋、鹌鹑蛋、猪肉松等。

蔬菜类：芹菜、油菜、胡萝卜、萝卜缨、芝麻、香菜、雪里蕻、黑木耳、蘑菇等。

水果与干果类：柠檬、枇杷、苹果、黑枣、橘饼、桃脯、葡萄干、胡桃、西瓜子、南瓜子、桑椹干、花生、莲子等。

孕中期补钙饮食同样记得要少食多餐，粗细搭配均匀，荤素搭配要适宜，并且对于补钙食物的选择应该多样化，不吃辛辣的食物！ ...

孕中期补钙产品怎么选

孕妇在孕中期每天的钙适宜摄入量是1000毫克，如果日常饮食中的钙摄入量无法保证，那么就要适量服用补钙产品来补钙，同样也需遵循缺多少补多少的原则。在挑选钙制剂时，选含钙高、含维生素的钙片是可以的，其次就是要注意钙源是否安全可靠。

1、在众多的补钙产品中，碳酸钙的含钙量为40%，其次氯化钙27%、碳酸氢钙23%、柠檬酸钙21%、乳酸钙13%、葡萄糖酸钙9%。1克碳酸钙含400毫克钙，而1克葡萄糖酸钙只含90毫克钙。孕早期理想的钙制剂应该是钙含量高的高浓度钙源如碳酸钙源。

2、维生素D能促进钙的吸收，冬季不方便晒太阳的孕妈不妨选择含有维生素D的钙剂进行钙质补充，维生素D可帮助肠道钙的吸收、促进钙离子在骨骼中的沉积和减少肾脏钙离子的排出。

3、孕妈在选购补钙产品时要仔细看一下产品的主要成分，是否含有“山梨醇”。山梨醇可以加快肠道扩张蠕动、调节肠内菌群，有效预防孕妇便秘。

4、孕妈在选用钙制剂时要注意厂家、厂址、生产日期、保质期、批号、批准文号等细节，避免买到伪劣产品。

5、孕妇朋友在怀孕期间摄取大量的糖分容易出现孕期糖尿病，选择补钙产品的时候应该偏重于选择无糖配方的，不含有糖、钠、胆固醇，更利于孕妇朋友和腹中宝宝的安全。

6、注意查看钙制剂的钙源，孕期是身体高度敏感的时期，来源于动物骨骼、牡蛎壳、扇贝壳和珍珠等的钙剂，长期服用容易引起孕妇重金属中毒，最好不要选购这类的钙制剂。 ...

孕妇孕中期补钙注意事项

钙对孕期妈妈是不可或缺的一份营养，但是孕妈妈在补钙的时候仍需要注意细节，勿因小失大。孕妇孕中期补钙注意事项也不少，建议大家耐心看完后再用科学的办法来补充足够的钙质哦！

1、少量多次补钙效果好这样比一次大量补钙吸收效果好。在吃钙片的时候，可以选择剂量小的钙片，每天分两次或三次口服。同样500毫升牛奶，如果分成2～3次喝，补钙效果要优于1次全部喝掉。

2、注意补钙的最佳时间。补钙最佳时间应是在睡觉前、两餐之间。注意要距离睡觉有一段的时间，最好是晚饭后休息半小时，这是因为血钙浓度在后半夜和早晨最低，最适合补钙。

3、肉骨头汤补钙是远远不能满足孕中期对钙质的需求的！肉骨头汤中脂肪量很高，喝汤的同时也摄入了脂肪，孕妈可不要将此作为唯一补钙方式，补钙还是需要饮食营养均衡才行。

4、补钙尤其要注意服用不含铅的钙片。在选择补钙产品时，应选择元素钙含量高的高浓度钙源如碳酸钙源，以充分满足补钙量的需求，从而减轻孕妇因服用过多片剂而导致的肠胃负担。

5、补钙尤其要注意服用不含铅的钙片。在选择补钙产品时，应选择元素钙含量高的高浓度钙源如碳酸钙源，以充分满足补钙量的需求，从而减轻孕妇因服用过多片剂而导致的肠胃负担。
