# 避坑“假”粗粮！这些才是助你刮油的粗粮圈王者

> 更新时间：2026-09-16 (UTC+8)

这个“五一”假期各位小伙伴有没有聚餐都吃什么好吃的啦？快！欢迎来留言

“过劳肥”的小小编和一群小伙伴吃了火锅、日料、烤串晚上总忍不住心有愧疚地整点粗粮“中和”白天那顿胡吃海塞的大餐红薯、玉米或芋头免不了的“粗粮”三件套真是粗粮界的“扛把子”吗？浙江大学医学院附属第一医院健康管理中心专家有话说
**真正的粗粮江湖**

**门派众多、高手林立**
除了我们熟知的红薯、玉米、芋头，还有小米、糙米、燕麦、高粱、绿豆、红豆、黑米……甚至土豆也偷偷混进了“大部队”，毕竟它是淀粉类蔬菜中的一匹“薯”马。

粗粮虽好，也有不少坑。今天，浙大一院健康管理中心营养师刘沉冰就带你一次搞懂。
2022年发表在《JAMA Network Open》杂志的一篇研究发现，虽然谷物、果蔬都是膳食纤维大户，但并非所有的膳食纤维对炎症水平的影响是相同的。谷物中的膳食纤维在降低炎症水平方面，效果远超水果或蔬菜。

**全谷物是啥？**

简单说，就是“未经抛光”的谷物，比如糙米、黑米、燕麦、荞麦……这些都保留了谷皮、胚芽的完整结构，富含膳食纤维、维生素B族，以及锌、铬、铁等微量元素。

粗粮包含了全谷物、杂豆类和薯类，富含膳食纤维，不仅能促进肠道蠕动、缓解便秘，还能延长胃排空时间，带来更持久的饱腹感，帮助控制进食量。此外，它们的碳水结构更复杂，消化吸收速度较慢，有助于稳定血糖水平，减少餐后血糖波动。

**怎么吃最有益？一日三餐巧安排**
《中国居民膳食指南》建议：成年人平均每天摄入200～300克谷类食物，其中全谷物和杂豆类占50～150克、薯类50-100g。

**我们跟着专家一起来明确粗粮类别**
**全谷物类：**包括小米、燕麦、高粱等。
**杂豆类：**比如红小豆、绿豆。**薯类（根块类蔬菜）**：例如红薯、土豆，由于含有较多淀粉，也被归为粗粮。吃粗粮也有“技术含量”，吃得时候，大家请牢记以下几个法则：
**三餐分配吃：**

不要把粗粮全堆早餐或晚餐，建议均匀地分配到一日三餐里，不要全部集中在某一餐。

**粗细搭配吃：**

**薯类+米饭类：**红薯饭（红薯块+大米）山药饭（山药丁+糙米或大米）芋头饭（芋头块+米）

**豆类+米饭类：**红豆饭（红豆+大米）绿豆饭（绿豆+糙米）扁豆饭（扁豆+大米或小米）

**多种杂粮混合饭：**二米饭（如大米+糙米/小米+大米）三色饭（大米+黑米+红米）

**杂豆杂粮饭：**大米+黑米+藜麦+燕麦+红小豆
此外，刘沉冰营养师提醒大家，并不是每个人都适合粗粮！胃肠“虚弱者”、老人、小孩，或本身就有消化系统问题的人，吃粗粮要“循序渐进、适量为上”。别拿自己当“全谷物战士”，结果第二天肚子唱“空城计”。
**这类粗粮谨慎选**

**有些可能是“假粗粮”**
尤其值得注意的是，大黄米、小黄米、糯玉米、黑糯米这类“软糯系选手”，虽然听起来很养生，升糖速度其实飞快，跟白米白面差不多。如果你是“血糖波动星人”，可得悠着点。避免吃黄米粥、白米粥，粥也不能熬太烂；选择甜玉米而不是糯玉米。搭配牛奶、大豆制品、杂豆、蔬菜等，增加蛋白质和膳食纤维，同时主食最好放在最后吃！
很多人爱把粗粮打成粉，然后兑水喝，觉得这样最养生。可惜你忽略了一个问题：粉越细，升糖越快！牛奶、豆浆富含蛋白质、脂肪、钙等多种营养物质，用它们冲粗粮糊，可以在一定程度上延缓升糖速度，而且口感还加分。

那么，日常生活中如何辨别真假粗粮食品？
**专家推荐“四看法”：**

**看原料：**一定要查看配料表，尽量选择全麦或粗粮排在第1位的食品。

**看含量：**全谷物要占51%以上才算数。

**看添加物：**加了太多糖、油，就别指望它健康了。

**看名字：**有“即食”字眼的，也是升糖好手。
